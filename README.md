# Instituto Mãos que Ajudam

## Sobre o projeto

O **Instituto Mãos que Ajudam** é um projeto desenvolvido como atividade universitária para praticar conhecimentos de desenvolvimento web.

O site representa uma organização sem fins lucrativos que realiza ações sociais, projetos de voluntariado e campanhas para ajudar pessoas em situação de vulnerabilidade.

O projeto possui três páginas principais:

- **Início:** apresentação do Instituto e informações sobre a organização.
- **Projetos:** apresentação dos projetos sociais desenvolvidos pelo Instituto.
- **Cadastro:** formulário para cadastro de pessoas interessadas em participar como voluntárias.
