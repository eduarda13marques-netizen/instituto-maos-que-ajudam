Sobre o projeto

O site do Instituto Mãos que Ajudam é uma organização sem fins lucrativos. Ele foi realizado como atividade universitária para praticar meus conhecimentos em HTML, CSS, JavaScript, Git e GitHub. O projeto é separado em 3 páginas: Início, Projetos e Cadastro de voluntários.

HTML

Usei a estrutura básica do HTML como ponto de partida. Usei as tags <nav>, <ul> e <li> para criar os menus e coloquei links para facilitar a navegação.

Utilizei a tag <main> para agrupar o conteúdo principal e, dentro dela, a tag <section> para separar os conteúdos em tópicos. Na página de projetos, foi utilizada a tag <article> com a mesma finalidade de separar os tópicos.

Na página de cadastro, utilizei a tag <form> para criar o formulário, a tag <fieldset> para agrupar os campos e a tag <legend> para identificar cada grupo do formulário. Também utilizei as tags <input> e <label> para criar e identificar os campos que o usuário deve preencher.

Nas três páginas foi utilizado o <footer> como identificação e informação do projeto.

CSS

Para facilitar a estilização, criei variáveis de cores utilizando :root. Utilizei Flexbox para organizar os elementos e Grid na organização dos projetos e do formulário.

Utilizei @media para tornar o site responsivo de acordo com o tamanho da tela. Também utilizei os estados :hover, :focus, :valid e :invalid para criar diferentes comportamentos visuais nos elementos.


Git e GitHub

Utilizei o Git para controlar as versões e registrar as alterações feitas no projeto. O projeto foi organizado utilizando branches, separando o desenvolvimento principal das novas funcionalidades.

Criei a branch develop para o desenvolvimento do projeto e a branch feature/acessibilidade para trabalhar nas melhorias de acessibilidade. Também utilizei uma branch hotfix/correcao para correções.

As alterações foram registradas por meio de commits, utilizando mensagens para identificar o que foi alterado. Depois, as alterações da feature/acessibilidade foram enviadas para o GitHub e integradas à develop por meio de uma Pull Request.

Também utilizei o GitHub para criar uma Issue relacionada às melhorias de acessibilidade e um Marco chamado Versão 1.0.0. Depois que as alterações foram concluídas e integradas, foi criada a versão v1.0.0 do projeto.

Dessa forma, o Git foi utilizado para controlar as alterações no código e o GitHub para armazenar o projeto, organizar as tarefas, revisar as alterações e registrar as versões.
